A capitulation-bounce bot that trades Coinbase Wrapped BTC (cbBTC) on 1-minute on-chain prices with $1,000 of paper money. It only buys a sharp selloff (close 130 bps below the close 30 minutes ago, or 180 bps below an hour ago), then rides the recovery to +220 bps, with a -100 bps stop, a 12-hour time stop and a profit lock once it is +150 bps up. Dev window: +18.10 USDC net, 1 round trip, max drawdown 1.50%.

## Run it

```sh
node main.ts
```
